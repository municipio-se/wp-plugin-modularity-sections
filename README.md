# Modularity Sections

This plugin is an LTS version of the Modularity Sections plugin v3.1.3. It
povides graphical sections intended for full-width usage.

## Installation

1. Install the package and its dependencies:
   ```bash
   composer require municipio/wp-plugin-modularity-sections
   ```
2. Activate the plugin in WordPress.
3. Activate the module under _Modularity → Options_.
